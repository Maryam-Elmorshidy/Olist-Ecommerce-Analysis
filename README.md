## 📌 Project Overview

This project explores the **Olist Brazilian E-commerce dataset** to analyze sales performance, order trends, and product categories using Microsoft Excel.

The goal was to transform raw data into meaningful insights through data cleaning, modeling, exploration, and interactive dashboard development.

## 🛠️ Tools & Techniques

- **Microsoft Excel** — Data analysis, PivotTables, charts, and dashboards.
- **Power Query** — Data cleaning and transformation.
- **Advanced Editor** — Editing transformation steps to handle specific data issues.
- **Data Modeling** — Establishing relationships between tables.
- **DAX** — Creating calculations and measures.

## 🔄 Project Workflow

| Step | Description |
|---|---|
| **01. Data Understanding** | Explored the dataset and understood the structure of its tables. |
| **02. Data Cleaning** | Cleaned and transformed the data using Power Query. |
| **03. Data Modeling** | Established relationships between relevant tables. |
| **04. Data Exploration** | Used PivotTables and charts to investigate patterns and relationships. |
| **05. Dashboard Development** | Presented the findings through interactive Excel dashboards. |

## 📊 Dashboards

The project includes four dashboards designed to explore different aspects of the business.

| Dashboard | Focus |
|---|---|
| **Main Dashboard** | Overall project overview |
| **Orders** | Order volume and delivery performance |
| **Sales** | Sales performance and trends |

## 🔍 Key Findings

- **Total Sales:** Approximately 13.22 million.
- **Total Orders:** Approximately 112.65K.
- **Delivery Rate:** Approximately 97%.
- **Top City:** São Paulo ranked first in both order volume and sales.
- **Sales & Orders:** A strong positive relationship was observed between order volume and total sales.
